# School Management System Customization

This document expands the customization requests shared by the school and groups them into clear modules, with short explanations of the expected function for each feature.

## 1. Dashboard

### 1.1 Quick Actions
- Training Videos
- Manage Students
- New Admission
- Attendance
- Send SMS
- Fee Management
- Result and Exams
- Income and Expense
- Family Management

### 1.2 Dashboard Widgets
- New admissions for the current month, with click-to-open details
- Total fee received and pending fee for the current month
- Daily present and absent counts for students and staff
- Upcoming birthdays
- Current month fee summary
- Total receivable
- Received amount
- Due amount
- Today's profit and loss
- Yearly admission graph
- Yearly fee graph
- School academic calendar
- Event management
- Class-wise list of students who paid fee today
- Class-wise list of students who were absent today
- Admin dashboard should show stats for all campuses

## 2. Banners

Suggested purpose:
- Manage homepage or portal banners
- Add, edit, activate, deactivate, and remove banners
- Schedule banners for specific dates or events
- Show different banners for announcements, admissions, exams, or holidays

Suggested features:
- Banner title
- Banner image upload
- Banner link
- Display order
- Status
- Start and end dates

## 3. Ads

Suggested purpose:
- Manage promotional ads or announcement cards inside the system
- Highlight campaigns, offers, events, or school notices

Suggested features:
- Ad title
- Ad image or banner
- Description
- Target page or module
- Display status
- Start and end dates

## 4. Admissions

### 4.1 Core Admission Features
- Admission inquiries
- Online admissions
- New admission
- Bulk import through Excel
- Custom admission form
- Admissions-related reports in PDF, Excel, and print

### 4.2 Bulk Import
- Export a sample Excel file from the system
- Allow staff or student data to be entered in that file
- Import students class-wise and section-wise in one click
- Support large uploads with validation before final save

### 4.3 Custom Admission Form
- Allow school to choose which fields appear in the admission form
- Enable required/optional field settings
- Support custom labels and form sections

## 17. Suggested Notes for Final Scope

- Add role-based permissions for admin, principal, staff, and parent
- Keep modules campus-aware so each branch sees only its own records
- Add PDF, Excel, and print exports wherever reports are mentioned
- Add SMS or WhatsApp integration where the document mentions messaging
- Validate all imported data before saving
- Keep audit history for edits, deletions, and bulk imports
